# Action Match の改善計画と実施状況

この文書は決定事項、既存の女の子版4枚の実施状況、新しい5動詞の画像制作と本体への組み込みの記録である。対象は4〜6歳。現在の人物基準、鮮やかな絵のタッチ、等幅2コマ、画像内の区切り線なし、アプリ側の赤い二重矢印を維持する。

## 1. カードの選択と並び

### 現在の動作（`index.html` の調査結果）

- 公開カードは既存の4動詞と追加の5動詞、計9動詞×男の子・女の子の18枚。HTML上の初期配置は動詞順、その中で男の子→女の子の順。
- `prepareActionCards()` は画面を開くときと「Play again」のとき、18枚の `.matched`・`.queued`・`aria-hidden` を解除してから、9動詞を `shuffle()` し重複なしで4語を選ぶ。各語の男女2枚からランダムに1枚を選び、選んだ4枚を再び `shuffle()` して先頭に表示する。残り14枚は `.queued` で隠し、DOM上でも後ろに置く。正解後はカードの位置を動かさない。
- `selectAction()` は残った動詞を `shuffle()` して次の正解指示を選ぶ。各動詞は1ゲーム内で1回ずつ正解になり、1ゲームは4問。正解カードは `.matched` となり、その位置を残したまま見えなくなる。
- 共通の `shuffle()` は Fisher–Yates 方式。元の配列を変更せず、カード選択・並べ替えと他場面のアイテム抽選に使う。

### 決定事項と実装

1. **実装済み：** 登録した9動詞から毎ゲーム重複なしで4語を選ぶ。表示は4枚、1ゲーム4問・各動詞1回。男女は動詞ごとにランダムで、交互にはしない。カードの上下順も Fisher–Yates 方式でランダムにし、DOM順を表示順に合わせる。
2. **実装済み：** 直前のゲームとの動詞・人物・並び順の重複は避けず、履歴も保存しない。反対の組（`Put it on.` / `Take it off.`、`Open it.` / `Close it.`）は同じゲームに出てよい。同じゲームで実際に迷う組が見つかったら、その時点で除外する組を検討する。
3. テスト側で `Math.random` を固定値に差し替えた3通りの抽選結果を再現する。`index.html` にテスト専用の関数・URLパラメータ・グローバル変数は追加していない。

### 既存テストへの影響

`tests/check-responsive-layout.mjs` は9動詞・各2画像、表示4枚、全18枚、`data-panels="2"` と二重矢印、画像寸法・はみ出し・タップを検査する。画像は4枚ずつの組にして検査する。固定抽選列3通りで9動詞の選択と上下順を再現し、同じ抽選列で開き直した際に同じ画像・位置へ戻ること、正解後に残りカードが移動しないこと、4問で終了すること、「Play again」で初期化されることを検査する。`tests/listen-drag-recovery.mjs` はAction Matchの出題順を検査していない。

テストは「4種類で重複なし」「画像の読み込み・寸法・二重矢印・タップ」「同一抽選結果での再表示は安定」を検査する。無作為の2回が必ず異なることは条件にしない。ChromiumとWebKitの3サイズ、最後はiPhone実機のChromeとSafariで確認する。

### 他モードとの対応

- **put-girl：同じ物・届け先の課題あり。** リビング Listen & Do に `cup → table`（「Put the cup on the table.」）がある。所有者は、別ゲームで同じ語を結びつける復習としてこの重複を採用した。
- **get-girl：同じ物・届け先の課題なし。** 洗面所にタオルの課題はあるが、届け先はタオルかけ・洗濯かご・男の子・シンク。棚から取る課題はない。`word-target-bookshelf-v1.png.webp` は本棚であり、タオル棚の完成絵ではない。
- **bring-girl：同じ物・届け先の課題あり。** 寝室 Listen & Do に `blanket → dad`（「Bring the blanket to Dad.」）がある。リビングには `blanket → mom` もあるが、届け先が異なる。所有者は寝室との重複を復習として採用した。
- **throw-girl：同じ物・届け先の課題あり。** リビング Listen & Do に `cookie-wrapper → bin`（「Throw the snack wrapper away.」）がある。所有者は重複を復習として採用した。現行の素材にはクッキーも描かれているので、制作時は包み紙だけを捨てる絵として読めるか確認する。
- Action Match の既存4語の英文は `Put it. / Get it. / Bring it to me. / Throw it away.` のままにし、追加5語は第3節のとおり。Listen & Do の具体的な英文・キャプションも変更しない。画像間で物の色・形を揃え、動作は Action Match の2コマで表す。
- Think & Say は本体のホームから遊べる実装済みのゲームで、本を扱うカードもある。今後 Action Match と同じ物を使う場合は名称と外観の一貫性を保ち、それぞれの絵が区別できるかを確認する。Think & Say の小道具や英文はこの計画だけで変更しない。
- 既存アイテムWebPは**生成時の参考画像**であり、そのままAction Match画像に貼り付ける方針ではない。人物・背景・物のタッチを揃え、素材のライセンスと公開サイズも確認する。

### 枚数、作業量、進め方

決定した作り直しは**女の子版4枚で、いずれも1枚ずつ所有者の承認を得て公開用へ差し替え済み**。基準画像と `docs/image-prompts.md` に沿った生成→緑背景の透過→WebP quality 84・800×450px→透過検査→比較表示を行い、旧版は非公開の `source-images/legacy/` に保管した。ブラウザでの回帰テストは所有者のMacでも実行して確認する。

**実施順序：** 既存の女の子版4枚の制作・承認・差し替えに続き、新しい5動詞の男女10枚も採用して公開ルートへコピーした。動詞データ・読み上げ対応表・4語抽選・関連テストの書き換えも実装済み。ブラウザでの回帰確認は所有者のMacで行う。

## 3. 追加した5動詞（男女10枚の画像を本体に組み込み済み）

新しい絵は時間帯が決まらないため昼服にする。既存の4動詞の絵はパジャマのまま維持する。各動詞の男女で小道具を変え、共通する動作を読み取れるようにする。

| 英文 | 男の子 | 女の子 |
|---|---|---|
| `Put it on.` | 黄色い丸いつばの帽子をかぶる（`action-put-on-boy-v3b.png.webp` 採用。もう一方の `action-put-on-boy-v3a.png.webp` は不採用） | 低い水色の丸椅子に座ってオレンジ（`#F28A24`）の無地の靴下をはく（公開画像 `action-put-on-girl-v3a.png.webp` はオレンジ版の内容）。左コマは奥の足に靴下、手前の足は裸足、手にはもう片方の靴下。右コマは両足に靴下 |

**進み具合：** 新しい5語（`Put it on.`、`Take it off.`、`Open it.`、`Close it.`、`Pick it up.`）の男女10枚を採用し、候補画像を残したまま同名で公開ルートにもコピーして本体に組み込み済み。

**確認事項：** 既存の4語（`Put it.`、`Get it.`、`Bring it to me.`、`Throw it away.`）の絵はパジャマ、新しい5語の絵は昼服なので同じゲームに混ざる。既存の `Put it.` と新しい `Put it on.` が同時に出ても迷わないか実機で確認する。`Close it.` の男女の絵はそれぞれ `Open it.` の絵と対になるが、決定済みのとおり `Open it.` と `Close it.` は同じゲームに並んでよい。

女の子の靴下の2動詞は、床に座る旧構図を使わず、低い水色の丸椅子に座り、体を右へ約30度向けた構図に統一する。
白い靴下の原版は `private-prototypes/action-match/` の v3a に残し、公開ルートの同名 v3a は候補 v4a から差し替えたオレンジ版とする。実際のカードのクリーム色の背景でも見え方を確認する。

**見送った動詞：** `push / pull` は2コマでは押したか引いたか分かりにくい。`carry` は `Bring it to me.` と重なりやすい。`give` は `Bring it to me.` と絵でも耳でも区別しにくい。
