## 候補画像の確認と残るリスク

- `Pull / Boy` は拡大したlayout-v5を正式採用。実機ではおもちゃ・車輪・ひもの視認性を確認する。
- Pushは椅子・カートが前方へ、Pullはおもちゃ・ドアが手前へ動く。女の子Pullはドアを開ける絵でもあり、既存の `Open it.` と意味が重なる。現在の `Open it.` は男の子の箱と女の子のカーテンで、現行登録は維持する。
- Giveは本・コップを子どもから近くの親へその場で渡す。Action MatchのBring登録は削除した。Listen & Doなど他ゲームのbring表現は対象外。
- Eatは食べ物を口へ運ぶ状態が見える。男の子のバナナの減り方は小さく、女の子のおにぎりのかじり跡の方が明瞭。
- 最終採用のv5×3枚とv3×5枚は利用者承認済み。Push女の子版カート周辺の微小な生成ノイズとEatの大きめの顔は承認どおり保持した。実ゲームで並べた際の見え方はMac/iPhoneで最終確認する。
- 上部ヒント帯と髪・頭部が一部重なることは利用者確認済みで許容。ヒント帯を避けるためだけに人物を縮小・移動しない。
- 実機では `Push` の椅子と机の距離、`Pull / Boy` の車輪とひも、`Give` の受け手の手、`Eat` の口元をカード寸法で確認する。

## Pull it. と Open it. の同時出題禁止: 実装済み

`prepareActionCards()` は `chooseActionTypes()` で4動詞を選び、各動詞の男女カードから1枚をシャッフルで選び、最後に選択カードを再シャッフルして縦4段に並べる。通常開始・リセット・Play Againはすべて同じ `prepareActionCards()` を通る。

競合関係は `actionConflicts=[['pull','open']]` としてデータ化した。競合を含む4動詞集合のみ引き直すため、通常のランダム性と男女・カード順のシャッフルは維持される。16動詞で競合がこの1組だけなら、無効な4動詞集合は全1,820組中91組（5%）。24回の上限に達した場合は、競合を避ける有限の選択へ切り替える。

ブラウザ不要のテストでは5,000シードで4動詞の一意性、Pull/Open排他、全16動詞と男女32画像の到達性、固定乱数が不正な組を繰り返しても停止することを検査する。
